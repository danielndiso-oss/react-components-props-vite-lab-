# Personal Blog

A simple personal blog built with React. This project demonstrates React components, JSX, props, and rendering lists of data.

## Features

- Displays a personal blog name and description.
- Shows a blog image.
- Displays multiple articles.
- Uses reusable React components.
- Passes information between components using props.
- Includes responsive styling.

## Components

- **App:** Main component that connects the other components and passes blog data.
- **Header:** Displays the blog name.
- **About:** Displays the blog image and description.
- **ArticleList:** Displays a list of blog articles.
- **Article:** Displays an individual article's title, date, and preview.

## Technologies

- React
- JavaScript
- JSX
- CSS
- Jest
- React Testing Library

## How to Run

1. Clone the repository.
2. Install dependencies:

   `npm install`

3. Start the application:

   `npm run dev`

4. Open the local address provided by Vite.

## Running Tests

Run:

`npm test`

## Project Structure

The application uses separate components to keep the code organized and reusable.
